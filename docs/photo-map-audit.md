# 4階案内図と施設写真の照合（作者用）

基準は現行案内図A4-06。旧原図A4-01は別資料のまま保持。現在の案内図では、来館者が必要な方向と入口だけを示す。西側旧番号の由来、研究区画、非公開階は画面に補記しない。

| 表示素材 | 館内図との対応 | 確認したこと |
| --- | --- | --- |
| 外観 | 地上4階の長い北面・東側の折れ | 街路から見たイメージ。階数と棟の輪郭を照合。4階の窓を個々の部屋と断定しない。 |
| ラウンジ | 4階東側、南側入口から北を向く | 正面と左は内壁。右のガラスは隣の廊下への間仕切り。右側通路の幅を確保し、外窓のない案内図に揃えた。 |
| 工房2 | 4階西寄り、東側入口から西を向く | 奥は内壁。長辺側に閉じた造形機器、入口から作業台への通路。工房1のレーザー加工とは分けて説明。 |
| 食堂・カフェ | 4階東端の外周区画 | 右側の外窓を許容する位置。PVに入れる前に、現行の窓割り・カウンター位置を再確認する。 |

| プレゼンテーションホール | 4階東側の内側。南西側入口から北へ | 外窓のない写真へ。北側の投影壁と斜めの間仕切りを確認。 |
| 3階ホール | 4階とは別の大ホール | 舞台と客席の写真。3階詳細図は公開面に出さず、窓の位置は未確定。 |

現行の図は概略の案内図であり、室内写真から寸法を確定しない。案内図とPDFを同じ座標データから生成。受付の強調、EVからの歩行経路、工房とラウンジの入口を追加。画像の拡大とPDFは従来どおり利用可能。

採用元・生成プロンプトは[画像台帳](media-assets.json)。月面居住区は構想図と表示し、現施設の内外観として扱わない。配管の試験資料は、止めた枝と流れる枝の見分けがつく作図を採用した。
