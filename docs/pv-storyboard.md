# 施設紹介PV 絵コンテ（制作資料）

**30秒／16:9／静止画と小さな動き。** タイトルは「ともに、明日をつくる。」。施設サイトと同じ食堂から始め、仕事に使うラウンジ、工房での試作と本の修繕、4階の企画展示を経て、見学窓口を紹介する。

掲示の受付場所、時間、版、通常の差し替え時刻は、サイトと同じ設定を参照する。17:06の差し替えと、返却控えや引継ぎに残る17:14は、同じ遅番の別の作業。映像の音を聞けない場合も、案内とその一拍は画面で確認できる。製本相談の写真は、2022年4月の活動報告と月をそろえて差し込む。

中央受付と工房2は、4階図で撮影方向を確認した素材を使う。金属試験片は企画展示の品として独立したカットにする。交流スペースの実景を挟み、模型から構想図へ移る。見学掲示は版、改訂年月、右下の差替時刻を同じ文字サイズにそろえ、時刻だけを拡大したり点滅させたりしない。環境音と二音はこの映像用に合成。24.55〜25.32秒は空調音を約11dB下げる。

PlaywrightとMicrosoft Edgeのある制作環境で `node scripts/render-facility-pv.cjs` を実行すると、確認映像と各カットの静止画を `.work/qa/pv/` に出力する。必要に応じてPlaywrightを含むディレクトリを `ASUNARO_NODE_MODULES` に指定する。お知らせに掲載する際は、映像の見学案内を2026年10月時点のものとして扱い、現在の受付状況は見学案内ページで確認できるようにする。

別担当は初版を等速で確認し、個別の手続きが進むように見えたと報告した。更新版の再確認では、390px相当でも受付場所と時間を読め、右下の変化は意識して視線を移したときに分かった。作者側では、書き出したMP4（1280×720、30.05秒）を等速で終端まで再生した。デコードしたコマで表示の前・中・後に受付場所と時間の描画が一致し、音声では該当箇所のレベルが約11dB下がって戻ることを確認した。

A4-08に合わせて受付写真を差し替え、確認用MP4を書き出した。21.2秒のコマで受付の表示と右手のガラス扉を確認。24.3秒、24.95秒、25.7秒のコマを比較し、受付場所と受付時間の領域を保ったまま右下の版表示が変わって戻ることを確認した。

## 製本相談を加えた版の確認

別担当が旧版と改訂版をそれぞれ390px幅で確認。旧版では工房の造形機から金属試験片へ直結し、小さな「企画展示」の表記では造形場所を区別しにくかった。改訂版では日常の製本相談を挟み、展示と構想図の補助ラベルを大きくした。旧版を知った上で、デコードした代表フレームを比較し、改訂版の無音・等速再生は終端まで確認した。

作者側の等速確認では、映像は1280×720、30.044秒。地図帳のカットは約11.55〜14.50秒に表示。24.3秒、24.95秒、25.7秒付近の実フレームを比較し、案内と版情報を保ったまま、右下の時刻と文言が変わって戻ることを確認した。MP4の音声をデコードした計測では、該当区間が約11.1dB下がり、通過後は直前との差が約0.3dBだった。

## 展示会場を加えた版の確認

前版を知る別担当が390px幅、無音、等速で改訂版を最後まで再生し、再生中の18コマを確認した。試験片の次に展示ケースが映り、模型と構想図の連結した建物や窓が対応して見えた。展示会場、構想図、受付時間の表記は読め、右下の一拍は案内の読み取りを妨げなかった。

作者側では書き出したMP4（1280×720、30.01秒）を等速で再生し、24.32秒、24.98秒、25.71秒のデコード画像を比較した。版と受付案内を保ったまま差替時刻だけが変化し、元に戻った。音声は該当区間で約11.0dB下がり、その後は直前と同程度に戻った。

案内図A4-09の更新に合わせ、展示カットをラウンジ前通路の写真へ差し替えた。確認用MP4（30.01秒）の等速再生で、16.71秒に写真と「4階 ラウンジ前」が表示され、24.30秒、24.97秒、25.75秒で右下の表示が変化して戻ることを確認した。

製本相談の写真に「2022年4月」を追加した版を、作者側で390px幅・等速で終端まで確認した。MP4は1280×720、30.04秒。11.65秒で撮影月を読み取れ、24.32秒、24.98秒、25.70秒のコマで受付案内を保ったまま差替表示が変わって戻った。書き出した音声も該当区間で約11.1dB下がり、直前のレベルへ戻った。

## ラウンジを加えた版の確認

公開サイトと前版を知る別担当が、390px幅・無音・等速で新旧を確認した。前版では工房が映るまでカフェ付きの交流施設に見え、構想図の小見出しを読み落とすと実景に見える可能性があった。改訂版では冒頭の「仕事とものづくりの拠点」、4階ラウンジ、工房の順で用途が分かり、月面の画は構想図と読めた。ラウンジ前の展示が常設にも見えるという指摘を受け、模型のカットに「月の企画展示」と入れた。

作者側で最終MP4（1280×720、30.05秒）を390px幅・等速で終端まで再生した。デコード画像の7.30秒で個人席と打ち合わせ卓、17.40秒で「4階 ラウンジ前」と「月の企画展示」、19.65秒で構想図の表記を確認した。24.30秒、24.95秒、25.70秒を比較し、受付場所と受付時間を保ったまま右下だけが「17:14 呼出」に変わって戻る。音声の該当区間は約10.9dB下がり、その後は直前との差が約0.1dBだった。
