# 施設紹介PV 絵コンテ（制作資料）

**30秒／16:9／静止画と小さな動き。** あすなろの施設と見学を紹介する。タイトル「ともに、明日をつくる。」。施設サイトと同じ内観から始まり、工房の企画の一例として月の構想図が出る。

| 秒 | 絵・動き | 表示／音 |
| --- | --- | --- |
| 0–5 | 4階東側の食堂・交流スペース。木のベンチと、窓から差す午後の光。 | 「ともに、明日をつくる。」／室内音に短い二音 |
| 5–9 | 街路から見た建物外観。 | 「あすなろ産業支援交流施設」 |
| 9–14 | 4階工房2。造形機と、作業台に置いた試作品。 | 「道具を、つくってみる。」／室内の空調音 |
| 14–18 | 公開展示の月面構想図。 | 「月に、暮らしを持っていく。」／冒頭と同じ二音 |
| 18–23 | 中央エレベーターを出て右へ進み、左折した位置から見た4階中央受付。右手にラウンジのガラス扉、受付との間に東側へ続く通路。 | 「見学は、中央受付へ。」 |
| 23–27 | 見学案内画面。「確認中」から「受付済」に変わる間、右端の欄が約0.8秒だけ空く。 | 受付欄が空く間だけ空調音が遠のき、「受付済」と同時に戻る。 |
| 27–30 | 淡い緑の背景に施設マークと名称。 | 「ともに、明日をつくる。」と作品表示 |

不穏な一拍には必須の文書IDを置かない。音なしでも施設の紹介が伝わり、初見では映像のつなぎにも見える程度に留める。

中央受付と工房は4階図で撮影方向を確認した素材を使う。環境音と二音はこの映像用に合成。受付欄が空く24.55〜25.32秒は、環境音のレベルも同じ時刻で下げる。

PlaywrightとMicrosoft Edgeのある制作環境で `node scripts/render-facility-pv.cjs` を実行すると、確認映像と各カットの静止画を `.work/qa/pv/` に出力する。必要に応じてPlaywrightを含むディレクトリを `ASUNARO_NODE_MODULES` に指定する。字幕、サムネイル、サイトのお知らせ本文は公開用映像が確定してから整える。
