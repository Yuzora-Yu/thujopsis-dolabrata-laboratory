# 施設紹介PV 絵コンテ（制作資料）

**30秒／16:9／静止画と小さな動き。** タイトルは「ともに、明日をつくる。」。施設サイトと同じ食堂から始め、工房の試作と本の修繕、4階の企画展示を経て、見学窓口を紹介する。

| 秒 | 絵・動き | 表示／音 |
| --- | --- | --- |
| 0–4.6 | 4階東側の食堂・交流スペース。木のベンチと、窓から差す午後の光。 | 「ともに、明日をつくる。」／室内音に短い二音 |
| 4.6–8.2 | 街路から見た建物外観。 | 「企業とつくり手が集う場所。」／外気の音 |
| 8.2–11.5 | 4階工房2。造形機と、作業台に置いた樹脂の試作品。 | 「道具を、つくってみる。」／室内の空調音 |
| 11.5–14.5 | 青い布表紙の地図帳と、木の押さえ板。2022年4月の製本相談の写真。 | 「工房の製本相談」「使い続けるために、直す。」 |
| 14.5–17 | 4階企画展示に出した金属試験片。手前の試験片に、殻の内側の格子が見える。 | 「4階の企画展示」「金属3Dプリンターの試験片」／冒頭と同じ二音 |

掲示の版と通常の差し替え時刻は、サイトの見学案内と同じ表記。17:06の差し替えと、返却控えや引継ぎに残る17:14は、同じ遅番の別の作業。映像の音を聞けない場合も、案内とその一拍は画面で確認できる。製本相談の写真は工房で扱う身近な依頼の一例として差し込む。

中央受付と工房2は、4階図で撮影方向を確認した素材を使う。金属試験片は企画展示の品として独立したカットにする。環境音と二音はこの映像用に合成。24.55〜25.32秒は空調音を約11dB下げる。

PlaywrightとMicrosoft Edgeのある制作環境で `node scripts/render-facility-pv.cjs` を実行すると、確認映像と各カットの静止画を `.work/qa/pv/` に出力する。必要に応じてPlaywrightを含むディレクトリを `ASUNARO_NODE_MODULES` に指定する。公開時に動画外へ案内文を添える場合は、見学時間が2026年10月版の掲示に基づくと分かるようにする。

別担当は初版を等速で確認し、個別の手続きが進むように見えたと報告した。更新版の再確認では、390px相当でも受付場所と時間を読め、右下の変化は意識して視線を移したときに分かった。作者側では、書き出したMP4（1280×720、30.05秒）を等速で終端まで再生した。デコードしたコマで表示の前・中・後に受付場所と時間の描画が一致し、音声では該当箇所のレベルが約11dB下がって戻ることを確認した。

A4-08に合わせて受付写真を差し替え、確認用MP4を書き出した。21.2秒のコマで受付の表示と右手のガラス扉を確認。24.3秒、24.95秒、25.7秒のコマを比較し、受付場所と受付時間の領域を保ったまま右下の版表示が変わって戻ることを確認した。

## 製本相談を加えた版の確認

別担当が旧版と改訂版をそれぞれ390px幅で確認。旧版では工房の造形機から金属試験片へ直結し、小さな「企画展示」の表記では造形場所を区別しにくかった。改訂版では日常の製本相談を挟み、展示と構想図の補助ラベルを大きくした。旧版を知った上で、デコードした代表フレームを比較し、改訂版の無音・等速再生は終端まで確認した。

作者側の等速確認では、映像は1280×720、30.044秒。地図帳のカットは約11.55〜14.50秒に表示。24.3秒、24.95秒、25.7秒付近の実フレームを比較し、案内と版情報を保ったまま、右下の時刻と文言が変わって戻ることを確認した。MP4の音声をデコードした計測では、該当区間が約11.1dB下がり、通過後は直前との差が約0.3dBだった。
