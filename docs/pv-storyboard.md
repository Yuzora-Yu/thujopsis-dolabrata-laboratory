# 施設紹介PV 絵コンテ（制作資料）

**30秒／16:9／静止画と小さな動き。** タイトルは「ともに、明日をつくる。」。施設サイトと同じ食堂から始め、工房の普段の試作と4階の企画展示を経て、見学窓口を紹介する。

| 秒 | 絵・動き | 表示／音 |
| --- | --- | --- |
| 0–5 | 4階東側の食堂・交流スペース。木のベンチと、窓から差す午後の光。 | 「ともに、明日をつくる。」／室内音に短い二音 |
| 5–9 | 街路から見た建物外観。 | 「あすなろ産業支援交流施設」 |
| 9–14 | 4階工房2。造形機と、作業台に置いた樹脂の試作品。 | 「道具を、つくってみる。」／室内の空調音 |
| 14–16.7 | 4階企画展示に出した金属試験片。手前の試験片に、殻の内側の格子が見える。 | 「金属3Dプリンターの試験片」／冒頭と同じ二音 |
| 16.7–19.2 | 公開展示の月面構想図。 | 「月面居住区 構想図」「月に、暮らしを持っていく。」 |
| 19.2–23 | 中央エレベーターを出て右へ進み、左折した位置から見た4階中央受付。右手にラウンジのガラス扉、受付との間に東側へ続く通路。 | 「見学は、中央受付へ。」 |
| 23–27 | 館内掲示。受付場所と時間は固定。右下の版表示だけが一瞬「17:14　呼出継続」に差し替わり、元の表示に戻る。 | 平日9時〜17時、4階中央受付。版表示が変わる間だけ空調音を下げる。 |
| 27–30 | 淡い緑の背景に施設マークと名称。 | 「ともに、明日をつくる。」と作品表示、© YU-ZORA |

掲示は窓口で受け付ける見学の案内。版表示の時刻は窓口の受付時間より後で、後から「中央受付の引継ぎ控え」を読んだときに重なる。映像の音を聞けない場合も、案内とその一拍は画面で確認できる。

中央受付と工房2は、4階図で撮影方向を確認した素材を使う。金属試験片は企画展示の品として独立したカットにする。環境音と二音はこの映像用に合成。24.55〜25.32秒は空調音を約11dB下げる。

PlaywrightとMicrosoft Edgeのある制作環境で `node scripts/render-facility-pv.cjs` を実行すると、確認映像と各カットの静止画を `.work/qa/pv/` に出力する。必要に応じてPlaywrightを含むディレクトリを `ASUNARO_NODE_MODULES` に指定する。公開時に動画外へ案内文を添える場合は、見学時間が2026年10月版の掲示に基づくと分かるようにする。

別担当は初版を等速で確認し、個別の手続きが進むように見えたと報告した。更新版の再確認では、390px相当でも受付場所と時間を読め、右下の変化は意識して視線を移したときに分かった。作者側では、書き出したMP4（1280×720、30.05秒）を等速で終端まで再生した。デコードしたコマで表示の前・中・後に受付場所と時間の描画が一致し、音声では該当箇所のレベルが約11dB下がって戻ることを確認した。
