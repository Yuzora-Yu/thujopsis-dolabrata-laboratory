# 施設紹介PV 絵コンテ（制作資料）

**30秒／16:9／静止画と小さな動き。** 施設の公開展示を紹介する広告として最後まで成立させる。タイトル「月に、暮らしを持っていく。」。閲覧者に表示するのは映像と公開展示の案内。収録資料の読み方は本編で説明しない。

| 秒 | 絵・動き | 表示／音 |
| --- | --- | --- |
| 0–5 | 月面構想図。外からは冷たい灰色、窓だけに暖かい灯り。最初は固定、最後にわずかに近づく。 | 「月に、暮らしを持っていく。」／低い環境音、短い一音 |
| 5–9 | 建物外観を街路から。前カットの水平線と、最上階の長い窓のラインをつなぐ。 | 「あすなろ産業支援交流施設」 |
| 9–14 | A72公開展示。サイトと同じ三連の設備図で、外部補給を止め、下側の予備系統に切り替える。 | 「水を回す。」／ポンプの低い音 |
| 14–18 | 4階工房2。造形機の並びと、作業台に置いた試作品。 | 「必要なものは、そこで作る。」 |
| 18–23 | 4階の発表室。斜めの壁に沿って、南西側の入口から前方を見た画。 | 「記録を残し、次の人へ。」 |
| 23–27 | 試験表示が静かに停止。「系統復旧」から「引き継ぎ確認」へ移る瞬間、画面右端の受付欄が一拍だけ空欄のまま。人影、赤い警告、点滅は使わない。 | 音が一拍だけ途切れ、通常の環境音へ戻る。 |
| 27–30 | 施設マークと公開展示名。背景は構想図の窓の灯りへ戻る。 | 「月面居住技術プログラム／地上統合実証 A72」＋作品表示 |

不穏な一拍には必須の文書IDを置かない。音なしでも施設の紹介が伝わり、初見では映像のつなぎにも見える程度に留める。

無音の確認映像を作成済み。発表室と工房の画は4階図で撮影方向を確認したものを採用。PlaywrightとMicrosoft Edgeのある制作環境で `node scripts/render-facility-pv.cjs` を実行すると、確認映像と各カットの静止画を `.work/qa/pv/` に出力する。必要に応じてPlaywrightを含むディレクトリを `ASUNARO_NODE_MODULES` に指定する。YouTube用の音、字幕、サムネイル、サイトのお知らせ本文は公開用映像が確定してから整える。
