# 写真・画面の構図

人物写真は、誰が、何をして、どこを見ているかが一目で分かる構図とする。作業中なら視線と手の動きを一つの対象へ合わせ、人物紹介ならカメラへ目線を合わせる。

背景は面と自然な光で受け、人物の周囲に広い余白を確保する。道具は写している動作に必要なものへ絞る。人物の表情、身振り、複数の小物を同時に主役にせず、一枚に一つの焦点を置く。

写真の質感は、平成後期の小型デジタルカメラによる普通の施設記録を基準とする。自然な肌、室内の既存光、控えめな色を保つ。生成後は視線、手、物の接触、姿勢を等倍で確認し、掲載画面でもPCとスマートフォンの双方で確認する。

余白は画像内の構図とページ上の配置の両方で扱う。追加の要素を置く前に、既にある人物・見出し・写真の主従を確かめる。


## 入居企業のブランド

施設が掲載する画像の外枠とサイズは揃えても、会社自身のロゴまで同じシリーズへ寄せない。既存の業種を示すマークを生かし、和文・欧文の使い方、字の太さ、重心、背景、横組みや上下の配置に差を持たせる。

ナギサは和文主体の非対称な編集室の組版、青庭は苗の丸印と大きな明朝の二文字、トリムは黒と橙の強い斜体、リエゾンは青と橙の器に和文二段とした。既存SVGを元のファイル名で直接編集。ビットマップの代用品へ置き換えず、会社名と旧来のマークの連続性を保つ。

企業ヘッダーの名前も、一覧と同じ法人種別・カタカナ名・漢字部分の区切りを使う。見出しではinlineの語句として扱い、アクセシブル名へ余計な空白を加えない。
