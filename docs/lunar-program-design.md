# 月面居住技術プログラムと探索の余白

公開面の問いは「月面で必要なものを届けられないとき、どう暮らすか」。地上で水、記録、製作を一緒に動かし、機器の復旧と生活の再開を別に測る。公開展示はシステムの切替を紹介する。参加者の選別、拘束、運用上の決裁を展示の説明には載せない。

| 読む順番 | その時点で成立する理解 | 後から意味が変わるもの |
| --- | --- | --- |
| トップ、公開展示 | 月面の暮らしを地上で試す。どんな設備なら続けられるかを知りたくなる | 構想図の灯り。完成した基地を撮影した写真ではない。 |
| 切替試験、入居企業 | 二系統を使い、修理中も暮らしを途切れさせない。部材、供給、記録の作り方に理由がある | 給水枝を区画ごとに切り替えられる。同じ仕組みは供給差を意図的に作るにも使える。 |
| 初期の共同事業・説明票 | 環境が使いにくければ設備を直す。退出は参加者の選択 | 旧仕様と2022年設備受領の言い方の差を照合。 |
| 再編決裁、評価総括 | 輸送する装置や予備品を減らすため、同じ設備で役割を代替できる人を選ぶ運用へ転換 | 母の道具から始まった設計を、その道具を必要とする人を外す運用が借りている。 |
| 事案原本、移送記録 | 脱落を成功に計上した条件では、実際に誰が暮らしを支えたかを測れない | 施設が閉じても、採用された記録の運用先が残る。 |

年代：設立時は災害後の生活を支える技術が中心。2013年に設備の切替、2016年に生活環境実証の拡充。2022年の事業再編に遠隔地滞在と輸送費の条件が入り、2026年10月に月面居住の構想と地上展示を公開。A72の72時間は公開で紹介する試験条件で、長期拘束の期間を表さない。「第5次」の見出しだけで、第四次や実在する募集枠の存在を断定しない。

写真と図面では、観察して疑える手掛かりを残す。物理的につながっていない設備の絵で違和感を出さない。試験図の戻り口と弁の状態を読み取れることを優先し、その用途が後に変わるところで不安を作る。

制作上の参考：[NASAの地上隔離実験CHAPEA](https://www.nasa.gov/humans-in-space/chapea/about-chapea/)のように、設備故障や供給条件を地上で試すという発想を参照。作品の計画・施設・関係者は独自の架空設定。[スクウェア・エニックス公式番組](https://www.jp.square-enix.com/presents/info/20261030004472.html)で扱われるような、数値上の正しさと体感を分ける考え方を、説明量や導線に応用する。暗号を明かす前に、見比べて仮説を持てる形へ直す。
