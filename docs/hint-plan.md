## 1. 保存された募集案内から、退出できた当初の条件を読む

前提：consent。

根拠と、その時点で読めるページ：

- /members/records/CONS-2016-005/ — SAPLING · 171 / 263／閲覧者 ordis。確認する記載：RE-2016-002。
- /members/records/RE-2016-002/ — SAPLING · 186 / 263／閲覧者 ordis。確認する記載：/news/20160520/、参加を取り消した方。
- /news/20160520/ — ROOT · 036 / 263。確認する記載：14泊15日、居住費、施設を出て。

段階別ヒント案：

1. 同意書と一緒に渡された案内がある。
2. 配布控えには、現在の一覧にない元の記事の掲載先が記されている。
3. RE-2016-002から2016年5月20日の募集案内へ。外出制限と参加の取り消しを区別する。

作者用の解答・解釈：期間内の外出は不可だが、参加を終えることで退出できた。費用は事業負担だった。

次に接続する段階：revised-offer

## 2. 無償滞在の追加募集と、実施された検査を照合する

前提：residential-offer、institution。

根拠と、その時点で読めるページ：

- /members/records/RE-2022-006/ — BRANCH · 187 / 263／閲覧者 institution。確認する記載：/news/20220715/、OBS-2022-044。
- /news/20220715/ — ROOT · 046 / 263。確認する記載：家賃、無償、日次検査。
- /members/records/OBS-2022-044/ — SAPLING · 188 / 263／閲覧者 ordis。確認する記載：本人同意原本は受領できず、スタンドは日曜に妹に渡す約束です、ENV-2022-031。

段階別ヒント案：

1. 同じ募集でも、参加を終えたい人への説明は同じか。
2. 原稿と本人向けの検査票には、実施記録と一致しない部分がある。
3. RE-2022-006とOBS-2022-044を比較。投薬は簡単な日次検査の説明に含まれていない。

作者用の解答・解釈：本人の申出で終えられる条項が消えた。9月10日の本人控えでは中止と帰宅時期を尋ねており、別管理欄では拒否傾向として条件が維持された。薬剤変更の説明や同意原本は保存分にない。

次に接続する段階：closed-group
