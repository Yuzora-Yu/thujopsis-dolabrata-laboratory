- ヒントを追加する前に、根拠となる文章・画像が、その時点の閲覧者に読めるか確認する。
- 段階1だけで答えを渡さず、観察箇所、比較対象、具体的な操作の順に開示する。
- 迂回路は別の入口を用意し、同じ前提を省略してしまわないか確認する。
- 誤認を誘う資料には、後から検証して解釈を更新できる資料を対応させる。
- ヒント設計の根拠と文書間の時系列はtests/editorial.test.mjsで検証する。
- 写真の付箋とPDFは、実物の拡大・抽出結果で確認する。
