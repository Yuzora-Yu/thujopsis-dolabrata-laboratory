# 旧基盤の研究コンソール（作者用）

PROJECT_SIXTHのローカル実装を参照し、あすなろ専用の画面、プロトコル、保存先を構築する。元ゲームのAPI・会員・セーブ・通貨・キャラクターを共有しない。元リポジトリは変更しない。

参照先：C:/Users/ship2/Documents/06-Yu-zora/PROJECT_SIXTH/js/trials.js、shared/particles.js、shared/core.js、shared/config.js。関連作品への案内は、試験完了後の作者側フッターから https://yu-zora.com/games/Game06_project-sixth.html へ置く。

## 試験

- 呼称はハンドルネーム可、1〜24文字。生年月日や実名は追加取得しない。
- 五枚のカードから★を選ぶ試行を五回。正解位置を選択前に確定し、再読込や登録し直しで既に答えた試行を消さない。
- 粒子観測を一回。30秒、100粒子、五種類計16イベント。マウス・タッチ・キーボードで観測地点を指定する。
- カード完了後に粒子試験へ進む。中断時はカード記録を保ち、未完の粒子試験のみ再開できる。
- 合格点を本筋やEnd3の条件にしない。両試験を終えた場合だけ、End3で呼称宛ての感謝を追加する。

## 世界への接続

資料照会室の認証後に入れる独立した機器画面とする。固定の古い保存画面とは別の、現在も使用される更新系。試験画面の存在を表の施設サイトから直接案内しない。

戦時の人的資源選別を再利用する中で、災害時の危険察知・意思決定に優れた対象を探す一次測定へ転用された。榊原の時代に、単回の数値を在籍・退出の条件へ用いることは拒まれていた。少数回のカードの的中を、その人の価値へ変換する運用の歪みも残す。

終了後に、稲葉、青井、安積、夏帆、灯の過去の測定値を照合できる。現在の状態は深部の照会後に補われる。記録の終了を本人の帰宅と混同しない。任意の試験による迂回路とし、既存の入口・認証・結末を維持する。

呼称と結果は同じケースの追加項目として保存。既存の認証、照会、結末、閲覧履歴を初期化しない。別のケースの呼称や結果を表示しない。End3の感謝は実験への協力を称えるものではなく、本人たちが自分の名前で施設を離れるために資料を届けたことへのお礼とする。

## 実装と任意導線

受領簿0014、またはYH-2022-017 → AP-2022-028の追記から、/room/console/へ進む。公開の施設サイトと固定保存画面には入口を追加しない。原票照合は/room/console/subjects/。いずれも閲覧票による認証内に置く。

研究の運用条件はAP-2022-028に保存。五試行の的中率と、群内の協力・救護を別に扱う施設側の歪みが分かる。実験後のAS-2026-019には、外部協力者の呼称と測定値が併合され、読み手も対象へ含められていたことが分かる。End3後は継続照会を終了する。

研究原票は稲葉・青井・安積・夏帆・灯の五件。「原票保存分」には当時の用途と回付欄を残す。2016年の控えは機器調整係と本人、2022年8月19日分は居住受付から評価統括へ。外部照会者の写しには回付先が記載されておらず、個人領域にある併合控えから対応を読める。備考と公開取材を先に読め、数値は各原票の「測定値」で開く。後年の管理状態は日付を分ける。完全版ZIPにも過去の五件を適性測定原票.jsonとして収録するが、外部照会者の呼称や結果は添付しない。

Nodeの保存ケース、WorkerのDurable Object、静的版の同じブラウザーの保存ケースにconsoleTrialを追加。通常の再起動・公開版更新でも既存状態を保持する。静的版で保存先を消した場合や別ブラウザーへの引継ぎは従来の進行保存と同じ制約となる。

## 確認項目

純粋関数の封印済み正解・判定・中断と、HTTPの権限・CSRF・別ケース分離をテスト。ブラウザーでは実時間の30秒を計測し、ポインターの位置と判定、0.5秒制限、矢印キー・Space入力、カード間のフォーカス、原票解放、再読込、呼称訂正、スマートフォンの観測面を確認する。検出数に加え、成立した入力の件数を反応欄に表示する。観測の開始時にタイマー、盤面、反応欄を同時に収める。小さい画面でのみ粒子の表示径を補う。既存の通し操作は未受験と受験済みの両方で行い、End3へ進む必須条件が増えていないことを確認する。
