# 人物と文章の声（作者用）

人物はテーマの代弁者にしない。仕事で見るもの、避けたい損失、相手との距離によって、同じ出来事の書き方を変える。施設のお知らせは広報の文体で統一してよいが、引用、メール、日誌、付記まで同じ口調にしない。

## 各人物が知っている範囲

一般の入居者は、生活用具や設備の共同事業まで知る。測定の担当、設備の担当、記録の担当が同じ情報を持つわけではない。深町と久世は生存評価の決裁を知る。榎本は継承と移送を優先し、朝倉は現在の選別を止める側として振る舞う。公開記事の著者が、後に分かる真相を当時から説明しない。

倉橋と榊原に生前の相談関係があることは背景設定。作中の資料で確認できるのは、2021年の資料照会の試みと、文乃からの記録受領まで。相談関係があることだけを、2021年の例外申請が承認されたことや、告発原本が外部へ届いたことの根拠にしない。当時の倉橋が個々の被害をどこまで把握していたかも、現在の本文からは確定できない。

主要本文を書き換えた後、この表と実際の発言を照合する。人物ごとの癖を装飾として付け足すだけで、全員が同じ結論を話す状態へ戻さない。
