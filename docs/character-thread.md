# 母と娘から追う経路（作者用）

## 瀬尾文乃

1963年2月5日生まれ。地域の図書館で資料整理と読書相談を担当してきた。返却された本の感想を聞き、次に借りる一冊を一緒に選ぶことが好き。家では、料理帳の分量へ鉛筆で書き込み、手紙や買い物のメモに小さな花を描く。

2005年、病気で利き手を動かしにくくなる。便箋をしまった時期を経て、支援者と水野志帆の試作品を使い、自分の字で知人へ近況を送るようになる。道具を握れることに加え、家の引き出しへしまえること、翌日また取り出せることを要求する。支援を受けることも、別のやり方を選ぶことも本人が決めたいと考えている。

2006年、43歳で榊原の聞き取りに参加。書く速度と字形の一致では改善に数えられなかった生活を、具体的な手紙の相手とともに語る。榊原は研究の目的を問い直し、2007年に旧研究の再開中止を求める。2010年の設立準備会でも、文乃は本人が途中で参加を取り消せること、採録した意見を本人が確認できることを求める。

娘に自身の支援をすべて背負わせることは望んでいない。2012年の聞き取りでは、大学へ進む灯が、本人の面白いと思うものも作ってほしいと語る。2022年以降は、娘の所在と本人意思を確認するため施設へ照会し、新聞の取材を受け、三枝や倉橋へ資料を渡す。帰宅を一方的に決めるのではなく、娘が自分で返事をできる状態かを確かめようとする。

## 瀬尾灯

1994年3月14日生まれ。2022年7月の取材・8月の失踪時に28歳。2026年の救出時は32歳。

| 年月 | 年齢 | 経歴 |
| --- | --- | --- |
| 2012.04–2016.03 | 18–22 | 工学部で機械工学を専攻。CADと3Dプリンターによる試作を習得 |
| 2016.04–2020.03 | 22–26 | メーカーで設計開発。福祉機器に関わり、2018年から勤務形態を変更 |
| 2017.04–2020.03 | 23–26 | 夜間3年制養成課程。2018年から勤務形態を変更し、日中の臨床実習期間には休職 |
| 2020 | 26 | 国家試験合格・免許登録後、リハビリテーション施設へ転職。榊原と専門職として意見を交わす |
| 2021.04 | 27 | あすなろの工房で自助具を開発。母と勤務先の利用者の希望を聞いて試作 |
| 2022.07 | 28 | 鉛筆用グリップと取材記事。翌月の読書補助具公開を予告 |
| 2022.08 | 28 | 短期の用具試用と説明され、退出できない実証対象P-034へ移される |

母の生活が学びのきっかけだが、職業は本人が選んだ。作業療法士の仕事と設計を結び、母に加えて勤務先の利用者にも道具を提供する。2021年から工房へ通う設定とし、2012年の開設協力者や2014年の製作者としては扱わない。

経歴の現実性は、[厚生労働省の職業情報](https://shigoto.mhlw.go.jp/Occupation/Detail?occupationId=168)と、[夜間3年制課程・日中実習の説明](https://www.iwad.ac.jp/course/sagyou.php)を参考に点検した。作中の大学・養成校・勤務先を実在校や施設と同定する設定にはしない。

## 三枝律と朝倉紬乃

三枝は2016年から工房の製作支援に従事。自分の祖父にも灯の試作品を借り、焼き芋の冗談を交えて相談する。朝倉とは同僚。灯の退出を支援して権限を止められ、2023年6月14日に管理居室で死亡。外部診療の照会は未承認。15日に人事台帳で業務終了を処理し、公開プロフィールにもその旨を追記。家族と新聞には死亡を知らせていない。8日の工房連絡時点では型紙と料理帳の写しは工房の引き出しにあり、三枝がその晩に朝倉の机へ移した。貸出管理は事務局へ引き継ぐが、紙袋と未送信書類は朝倉が別々に保管する。

朝倉は1993年生まれで灯と一つ違い。2021年、工房に来た灯へ機械と材料を案内し、三枝と一緒に試作を支える。三枝を失った後、榊原の判断を固定すれば人を失わずに済むと思い込む。二人への愛着があり、本人の原文も捨てないが、帰宅の希望より判断モデルへの一致を優先する。

## 情報を出す順序

1. 制作物0021から灯の取材記事へ。母の便箋、写真の髪、焼き芋の会話を通じて暮らしに触れる。
2. 翌月の新作がなく、プロフィールだけ活動終了になっている。公開側に内部の貸出番号は出さない。
3. 返却窓口の変更に伴う川瀬宛ての連絡から、共同試作の会話へ。灯が母の料理帳を試した後、三枝が控えを探している。文書IDを照会すると貸出・返却票と新聞切抜を読める。公開された活動終了の日付と、家族が本人を捜し始めた日を比べられる。
4. 評価企業の権限でP-034と灯の名前が一致する。短期試用の説明と、実際の継続条件が食い違う。
5. アシタのAH-2017-009から初めて旧基盤のURLを知る。公開沿革には旧サイトへのリンクを置かない。保存室には三枝の不在を報じる続報もある。
6. 機関領域で、設立の原点が母の文乃だったことと、その娘が対象者にされたことを知る。FUM-2010-002の本人意思とFAM-2022-009の代理回答を比較できる。
7. SA-2023-012で、三枝の業務終了が帰宅を意味していないと分かる。
8. 告発者の個人領域で、三枝の原文と灯の便箋を読む。愛着と、本人の意思を認めることがすれ違う。
9. 第三の結末で、本人の希望を確認して灯を救出し、母の料理帳と型紙を返す。帰宅後の食事と、自分のペースで続きを作る連絡を残す。三枝の不在は消さない。

## 中心となる原本

- OR-2006-004：母・文乃の生活を聞き取り、研究の目的を問い直す。
- FUM-2010-002：母が設立準備に寄せた、本人の選び直しと参加撤回の条件。
- FAM-2022-009：母からの所在照会と、本人の声を取り次がない代理回答。
- YH-2022-034：娘の対象者登録と帰宅希望。
- SA-2023-012：帰宅を支援した三枝の原文と、運営側の終了処理。
- AS-2023-008、P034-2026-102：朝倉が保管する友人と本人の原文。

この人物経路は、企業・旧図面・新聞の経路と並行する。サイト内にゲームの操作チュートリアルは置かない。
