# 作品から人を追う経路（作者用）

## 中心人物

- **瀬尾灯（1979年生）**：母のために始めた自助具の制作を、周りの人にも広げていった個人会員。物の使いやすさだけでなく、しまう引き出し、家族との食卓、本人の字を大切にする。施設や研究のために登場した人ではなく、帰る生活と作りかけの仕事を持つ人として描く。
- **三枝律**：2016年から工房の製作支援に従事。自分の祖父にも瀬尾の試作品を借り、冗談を交えながら相談する。朝倉とは同僚。瀬尾の退出支援を申し出て権限を止められ、2023年6月に管理居室で死亡。外部診療への照会は未承認。死の機序は描写せず、拒まれた支援と改変された台帳を根拠にする。
- **朝倉紬**：若い頃、瀬尾に模型の組み立てを教わった。三枝と瀬尾への愛着は本物。三枝を失った後、榊原の判断を固定保存すれば人を失わずに済むと思い込む。友人の原文を大切に保管しながら、その人の望んだ「本人に決めさせる」という条件を採用しない。
- **榊原恒一**：2006年の聞き取りで瀬尾と母の便箋に出会う。旧評価票では改善として数えられなかった「自分の字で手紙を書く」を前に、旧研究再開への協力を断ち、2007年に中止を求める。再開案は凍結。2010年、新たな法人を設立。

## 情報を出す順序

1. トップの制作物紹介から鉛筆用グリップ、取材記事へ。母の便箋、髪が跳ねていた写真、焼き芋の冗談で生活と人柄に触れる。
2. 翌月の掲載がなく、作者のプロフィールだけ活動終了になっている。普通の試作受付番号が残る。
3. 最初の会員領域で貸出票と共同試作の会話を読む。返ってこないのは道具だけではないと分かる。
4. 評価企業の権限で初めて、P-034と名前が一致する。短期試用の説明と実際の継続条件が食い違う。
5. 機関領域で、施設の原点となった人が対象者にされたことと、その人を帰そうとした三枝の抵抗を知る。
6. 告発者の個人領域で、三枝の原文と瀬尾の便箋を読む。二人への愛着があることと、朝倉の計画に同意できることは別になる。
7. 第三の結末では「全員保護した」の一文で終えず、瀬尾が家で母と食事をし、自分のペースで制作を続ける場面を置く。三枝の不在は消さない。

この経路は既存の企業・旧図面・新聞の経路に並行する。通る順序を固定せず、公開の氏名検索と同じ文書IDの照会で接続する。記事内にゲームの操作説明を追加しない。
