# 識別番号の規則（作者用）

番号を見て推測できることと、本文で確認しないと分からないことを分ける。これをプレイヤー用の一覧として掲載しない。

| 系統 | 付け方 | 読み取れること／意図的に分からないこと |
| --- | --- | --- |
| 入居者紹介、制作物、収蔵目録、受領簿 | 系統ごとに独立した4桁の掲載順 | 連番の間に掲載されていない項目があること。企業の登録番号や部屋番号は表さない。 |
| 会員ID | 入会日8桁＋台帳番号4桁。個人は台帳のP符号を含む | 一組目は現物の写真から。他の名義では日付と番号を照合できる。機関0000を初期画面から推測で確定させない。 |
| 旧資料照会室の閲覧票 | H＋交付年の下2桁＋契約時の台帳番号。照会符号は発行時に別欄へ記録 | H17-0038は2017年交付の保守契約用。照会符号は移管作業票で確認する。退去後も保守契約が続く場合は同じ票を使う。 |
| 研究資料 | 事業・管理系列＋起票年度＋系列内番号 | YHは翌檜、FABは工房、AHは移管、ASは個人保管。系列は所有者や閲覧権限を保証しない。 |
| 設備台帳 MX | 起票年度＋作業範囲の先頭室番号 | MX-2019-410は西側の410から始まる点検範囲。案内図の版や入居者の掲載番号とは別。 |
| 別紙・照合 | 元の番号に枝番。例：YH-2018-041-A、HC-2021-031-R | 別紙A、照合用の複写を推測することは可能。ファイル名を知っても閲覧権限は得られない。 |
| 対象者 | P-034など登録時の個票番号 | 退去の公開表示が変わっても同一人物。P034-2026-102は対象者別に起票された系列。YH-2022-034は登録番号に合わせた個票。 |
| 図面・旧史料 | A4-01は4階案内図の原図番号。KS-1943-06など旧収蔵番号は当時の短い桁数を保持 | 作図・公開・保存は別日。管理番号で昔の区画を照合できるが、現在の位置や運用は資料で確かめる。 |
| A72 | 月面居住技術プログラムの公開展示符号 | 72時間の試験条件。会員領域の文書番号でも、被験者群の番号でもない。 |

起票年度と作成日が異なる場合は、後から番号だけを振り直さない。YH-2019-026は2019年に起こした継続案件の2020年作成版。補記は日付を付し、元の文書を未来の事情で上書きしない。新聞の初刷、訂正、事務局発表も別に保存する。

連番や別紙の推測は遊びとして許す。規則から導けない一件に行き当たるまで総当たりを求めず、前後の欠番、本文、受領票のうち二種類以上で次の行動を支える。文書IDを増やす場合は本文の引用と閲覧権限をテストし、表示する一覧には必要なものだけを出す。
