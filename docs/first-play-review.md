# 初見確認の進め方（作者用）

第三者へ渡すものは、確認対象の公開版URLと「普段どおり興味のある所を見てください」の一文。作品の正体、探すべき数字、SEEDの回数、エンディング数は事前に渡さない。行動記録を自動収集する仕掛けは加えず、本人が同意した範囲で終了後に聞く。

| 観察点 | 終了後に尋ねること | 修正の目安 |
| --- | --- | --- |
| 最初の画面 | どんな施設に見えたか。続けて何を見たかったか | 宇宙の画像に興味を持っても、地上で何を試す施設か分からなければ本文とCTAを整える。 |
| 公開展示からの寄り道 | 自分から選んだページはどれか。どの設備の何が面白かったか | 制作物が無関係な小物の羅列に見えた場合、研究との関係を見せる実例を選び直す。 |
| 最初の違和感 | 気になった箇所と、それを見直した理由は何か | 全員が同じページへ直行する必要はない。文面に教えられただけの場合は案内を減らす。 |
| 足が止まった所 | 行き先が分からなかったのか、確認する操作が分からなかったのか | 前者は別の根拠を一つ追加。後者は表示や操作を直し、答えを直接書かない。 |
| 見方が変わった瞬間 | 初めと後で意味が変わったものがあったか | 表の説明に戻りたくなる資料を優先する。説明文を読み切ったことだけを成果にしない。 |
| 余韻 | 閉じたあとも残った場面、あるいは怖さが途切れた場面は何か | 不穏な表示の量よりも、本人が確かめた因果関係を直す。強い演出は増やす前に頻度を見直す。 |

作者の再確認と、人が初回に自由に探索した観察は別に記録。未到達は失敗として丸めず、何に気づいてどこで別の関心へ移ったかを残す。必要な情報が隠れていることと、操作が分かりにくいことを混同しない。
