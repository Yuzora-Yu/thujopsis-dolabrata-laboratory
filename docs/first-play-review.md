# 初見確認の進め方（作者用）

第三者へ渡すものは、確認対象の公開版URLと「普段どおり興味のある所を見てください」の一文。作品の正体、探すべき数字、SEEDの回数、エンディング数は事前に渡さない。行動記録を自動収集する仕掛けは加えず、本人が同意した範囲で終了後に聞く。

| 観察点 | 終了後に尋ねること | 修正の目安 |
| --- | --- | --- |
| 最初の画面 | どんな施設に見えたか。続けて何を見たかったか | 働く場所、相談できる工房、見学のどれが伝わったかを確認する。 |
| 表のページでの寄り道 | どの制作物や人の話が印象に残ったか。豆知識を見つけたか | 道具の使い手や作り手の言葉が、次のページを開く理由になっているかを見る。月の展示は、興味を持った人が寄り道できる位置に置く。 |
| 最初の違和感 | 気になった箇所と、それを見直した理由は何か | 全員が同じページへ直行する必要はない。文面に教えられただけの場合は案内を減らす。 |
| 足が止まった所 | 行き先が分からなかったのか、確認する操作が分からなかったのか | 前者は別の根拠を一つ追加。後者は表示や操作を直し、答えを直接書かない。 |
| 見方が変わった瞬間 | 初めと後で意味が変わったものがあったか | 表の説明に戻りたくなる資料を優先する。説明文を読み切ったことだけを成果にしない。 |
| 余韻 | 閉じたあとも残った場面、あるいは怖さが途切れた場面は何か | 不穏な表示の量よりも、本人が確かめた因果関係を直す。強い演出は増やす前に頻度を見直す。 |

作者の再確認と、人が初回に自由に探索した観察は別に記録。未到達は失敗として丸めず、何に気づいてどこで別の関心へ移ったかを残す。必要な情報が隠れていることと、操作が分かりにくいことを混同しない。

公開前の見直しは、まずトップと主メニュー、404、欠番から読める企業・制作物を対象にする。案内の名称が遷移先と一致するか、料金・時刻・場所が別のページでも同じか、日付が発行・撮影・追記のどれを指すかを照合する。次に、意図して食い違う記載には別の資料から確かめる手段があるかを見る。

独立したブラウザーエージェントによる序盤の確認では、月の企画展示から小物ケースに進み、ギャラリーの欠番から未掲載の制作物へ到達した。資料番号を公開検索に入力して結果がなく、調べ先に迷った。検索範囲を公開ページと明記し、通常の会員サイトへの入口を維持する。ギャラリーの制作方法の絞り込み不良と、ミナモの本文と配管図の流れの相違は修正対象とした。人が初めて遊んだ結果とは区別する。

欄外の印は八つの公開ページと見学案内に一つずつ置く。発見前に番号や総数は表示しない。発見後は各控えに番号を表示し、同じブラウザーで重複なく記録する。9番は見学案内の版情報に添えた差し替え時刻に紛れている。初めて開いたときに、通常の15回到達と同じ異変が始まる。全9件の控えは副次的な発見とし、主経路の資料番号や認証情報は収録しない。

配置を変えた後の短い独立試遊では、写真側の太陽、設立者名の横の印、制作方法の横の羽根が見つかった。9番には到達しなかった。9番の動作確認はこれとは別に、作者が場所を把握した通し操作で行う。沿革の末尾で二つのリンクがつながって見えたため、間隔を設けた。

対象ページを以前に確認した別担当が、公開版の404から新規ブラウザープロファイルで経路を再現した。会社一覧では掲載番号と号室が別の順であることを確認。活動報告の机の写真は、拡大と横方向の移動で読めた。写真が操作できることは通常の表示から分かりにくかったため、各社の写真と図に共通の操作表示を加えた。ログイン後に選んだ行き先は、会員トップにある灯の次の試作の連絡だった。

更新候補の再試遊では、取次担当者の氏名を公開検索して0件だったため、評価分野と入居時期を見比べて欠番を選んだ。代表者が取次担当者と一致し、同じ文書IDを別名義で照会できた。集計報告は経由していない。作者側では320〜1280px幅でカードの収まりを確認し、390pxでは最初の欠番を挟むカードを同じ画面で確認した。
