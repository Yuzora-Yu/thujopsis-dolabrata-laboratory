# 募集から生存評価へ（作者用）

## 設定

2016年は、設備と生活用具を調整するための居住実証。参加中の外出制限はあるが、本人が参加を取り消せば帰れる。居住費・飲食費は事業負担。朝夕の聞き取りを除き、館内で自由に過ごせる。これは榊原の理念と両立する。

2022年の改訂では、同じ無償滞在を掲げながら、退出の条件が運用担当による面談へ変わる。灯はさらに短い補助具試用と説明され、継続群へ編入された。期間中の全館利用という説明も、実際の群別通行許可とは一致しない。

実施されたのは、未告知の投薬と評価端末による群内対立の誘導。運営は、他者を排除して生存した者を優秀と判定し、旧継舟の保存優先へ対応させる。重大な殺傷と救護要請にも介入しない。作為的に生じさせた結果を、参加者の自発的な能力として採用する研究である。

前理事長の生前に始まった集計除外と退出保留から、死後の生存選別へ進行する。朝倉はこの方式を止めようとする一方、全員の応答を前理事長の原型へ一致させるまで帰さない。二つの運営は、救う人を選ぶ方法が異なるが、本人の退出意思を保留する点で重なる。

## 人物を先に知る

2022年4月の製本相談では、吉野夏帆、青井真、瀬尾灯が本と押さえ板を直している。夏帆は書き込みを消さず、持ち主の本へ戻すことを大切にする。プロフィールの言葉は、後に返却済みへ書き換えられた私物の記録と対照になる。

灯の料理帳と読書具の試作は、母、夏帆、青井、三枝をつなぐ。青井はP-031として現在もB-06にいる。夏帆はP-033として2022年9月11日の事案で死亡。彼女の本を返却済みにしないでほしいという灯の原文が工房へ残った。生存者を序列だけで人物評価する構成にしない。

## 表示と点検

通常のお知らせは54件、公開一覧は32件。年・種別で絞り込み、1ページ12件とする。募集記事は当時の説明文を保ち、後年の告発資料を本文から直接紹介しない。古いお知らせへ、後に作成された文書を当初から記載しない。

SEED15回目からの異変は、施設案内・会員案内・食堂・工房・お知らせにも断片を置く。SEED外への到達で演出だけを解除し、認証と結末は保持する。作品番号の欠番を調べる経路と、記事から人物を追う経路の双方を残す。
