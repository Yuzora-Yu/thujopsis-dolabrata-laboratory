# 探索体験の再設計（作者用）

この資料は公開しない。ページ数、実装件数、テスト数を完成度の代わりにしない。欠点を見つけた場面と、修正後にプレイヤーが実際に経験できることを対にして確認する。

## 現状の問題

| 項目 | 現物の問題 | 修正で確かめること |
| --- | --- | --- |
| 語り手 | YH、FAB、HC、ASなどで同じ「本人意思・保全・別の問題」という説明が反復される | 研究者、製作者、被験者、事務担当の利害と書き方が違い、原文から立場を推測できる |
| 推理 | EV・GRの追記が原因と結論をそのまま説明し、次の文書IDを渡す | 検査、通知、救護、集計の記録を比較した結果として、運営が条件を作ったと分かる |
| 危機感 | 閲覧しても施設の反応が変わらず、ほぼ過去の資料を読むだけ | 照会履歴が作中で使われ、現在の人物が反応し、外部から読んでいる存在が認識される |
| 人物の厚み | 文乃・灯・三枝・夏帆が似た倫理的主張を述べる | 日々の作業、失敗、冗談、言いよどみ、望みの食い違いから人物を好きになる |
| 告発者 | 朝倉が榊原に救われた内容と、なぜ今動くのかが曖昧 | 2012年の具体的な出会い、2023年の喪失、2024年以降の歪み、2026年の切迫をつなぐ |
| 時系列 | 元の文書へ後年の文を何度も追加し、誰のどの時点の判断か混じる | 原本と後年の追記を分け、作成者・追記者・参照先の成立時期を確認できる |
| 形式 | 研究資料のほとんどが同じ見出しと数段落 | 仕様、受領簿、メール、返却票、日誌、面談、データ表が、その用途に合った形で残る |
| 操作 | 長い文書番号を覚えて往復する負担がある | 文書照会システムとして自然な閲覧履歴・復帰・文書内移動が使え、解法を説明しない |
| 画像 | 顔・視線・手・接触を検証する前に採用した | 手のある写真は複数候補を比較し、指のつながりと物の接触を等倍確認する |
| 世界 | 18企業の業種はあるが、人の生活や協力・対立が薄い | 無関係な仕事も続く施設の中に、退去、依存、黙認、抵抗の異なる経緯がある |
| 結末 | 提出後の数段落だけで片付く | 自分が渡した資料と相手の利害が結末に反映され、失われたものと救えたものが残る |

## 体験の5区間

| 区間 | 感情の変化 | 追いたくなる問い | 主な証拠と操作 |
| --- | --- | --- | --- |
| 序盤 | 普通の施設への親近感から、小さな不在へ | 来月も作ると言っていた人は、なぜ続けなかったのか | 制作記事、写真、掲載番号の欠落、消えたメニュー |
| 中盤 | 記載ミスという解釈から、意図的な処理へ | 退去した名前が、なぜ測定や納品に残るのか | 異なる権限の同じ照会、公開記録と個票、旧図面 |
| 深部 | 過去を読む安全な立場から、現在の照会者へ | 読んでいることを、誰が知ったのか。今も人がいるのか | 旧基盤の継続更新、原本と追記、閲覧・照会への反応 |
| 告発 | 助けたい人への信頼から、救済の意味への疑いへ | 私が資料を渡すことは、誰を何へ引き渡すことなのか | 生きている返答、ZIP、氏名と個人領域、採否と未送信原文 |
| 結末 | 提出による達成感から、残った責任へ | 閉館と研究停止は同じか。本人に戻ったものは何か | 提出先ごとの利害、移送記録、保護、記録の行方 |

## 改修の順序

1. 事実、原本、追記を一つの資料定義へ整理する。既存のURL・認証・利用状況は保持する。
2. 主要人物の経歴、望み、怖れ、仕事、文章の癖を定義し、本文へ反映する。
3. 公開記事から資料、人物、現在の反応へ至る情報依存を組み直す。同じ説明を重ねている場所を削る。
4. 読む・照会する・渡す行為が、作中の記録や人物へ返る進行を実装する。端末の実際の侵入や個人情報収集は演出の前提にしない。
5. 画像、図面、文書形式、余白、操作を場面ごとに点検する。
6. 区間ごとに画面の証拠だけをたどり、行き詰まり、先回りした解答、同じ感情の反復を再修正する。

## 完了を判断する根拠

- 5区間それぞれで、読む前と後で変わる仮説、人物への感情、次にしたくなる操作を実際のページで示せる。
- 主要人物の原文を名前なしで読み比べても、仕事と感情の違いが分かる。
- 過去の出来事、後から書かれた説明、現在の反応が混同されていない。
- 隠された場所へ進むための根拠があり、文書番号や日付の無意味な総当たりを要求しない。
- 正しい結論だけを説明するページではなく、誤認と訂正、信頼と反転を体験できる。
- 画像の採否を、生成した回数や低解像度表示でごまかさない。
- 技術確認に加え、恐怖、引き、人物、操作、自然さ、図像の各観点で指摘した欠点を再確認する。

## 再構成後の判断

48資料を原本・追記・時刻別記録・表へ組み直し、集計の分母、救護拒否、偽通知、原文の採否を読む側が照合する形へ変更した。便利な閲覧履歴が、後の対外照会資料で観察記録へ反転する。施設側の照会確認、生存者からの紙、ST-04の現在の返答、外部協力者の採録を順に出す。

個人領域の入口は研究ノートと三枝の封筒の二件。採否表、移送控え、独立照会へは本文の番号で進み、完全版ZIPは移送控えから取得する。全資料と出口を入口へ並べていた構造を廃止した。

[探索読解と修正根拠](route-reading-audit.md)に、区間ごとの仮説、反証、次の操作を記載。Node・静的版・Workerでの操作確認と、初見の人による面白さの評価は区別する。
