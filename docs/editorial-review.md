# 情報開示と整合性の点検（作者用）

公開サイトには含めない。探索の根拠となる入力は[検索語・文書ID一覧](critical-search-words.md)、段階別の解答は[ヒント設計](hint-plan.md)を参照する。

## 読み進める理由

| 最初に残す疑問 | 次の根拠 | 深部で分かること |
| --- | --- | --- |
| 来月も作ると言っていた灯は、なぜ活動を終えたのか | 取材、プロフィール、FAB-2022-071、新聞切抜 | 制作者が試用協力からP-034へ登録され、家へ戻れていない |
| 活動を終えた人の寸法票が、なぜ届き続けるのか | YH-2022-034、継続運用の原本 | 公開台帳の利用終了と、実験の終了を分けている |
| 元の施設は誰のために作られたのか | 文乃の聞き取り、OR-2006-004、FUM-2010-002 | 母の生活と選ぶ権利を原点とする施設が、その娘の退出を拒んでいる |
| 三枝は灯のために何をし、どうなったのか | 共同試作の連絡、続報、SA-2023-012 | 退出支援が止められ、死亡を業務終了の一語で覆われた |
| 朝倉は友人を助けようとしているのか | 受領ZIP、AS-2023-008、P034-2026-102 | 愛着と保全の意思はあるが、本人の帰宅より原型への一致を優先している |
| 匿名通報すれば研究は終わるのか | 保全先の案内、TR-2026-011、完全版ZIP | 施設閉鎖と研究停止は異なり、外部継承の原本も独立調査へ渡す必要がある |

公開取材では、髪の跳ね方、引き出しの寸法、焼き芋の冗談を残す。後から被害の説明だけで人物を知る構成にしない。文乃にも仕事、好み、娘への希望、照会を続ける行動がある。

恐怖は、帰る意思が記録されていても扉が開かないこと、本人と物品を同じ返却手続きで管理すること、判断を固定すると原文の願いが捨てられることから生じる。露骨な損傷の描写や、現実の端末への侵入を装う表示には依存しない。

## 設定を照合した範囲

- 灯は1994年3月14日生まれ。2022年取材・失踪時28歳。機械工学、メーカー、夜間養成課程、2020年免許登録、2021年工房利用の順。日中の臨床実習に勤務調整を置いた。
- 設立の原点は母の文乃。2006年43歳、2012年49歳。2012年の娘は大学進学直前で、当時の開発者として扱わない。
- 2022年8月19日付の再編決裁と試用登録、22日の旧基盤受領、23日の家族の届出、31日の公開登録終了、9月の新聞記事を分けた。
- 受領簿0002・0005・0007・0008では、後年の文書番号を追記日とともに記載。更新日はデータ側で保持し、描画モジュールの副作用で補わない。
- 訃報の病気説明、新聞初報の自殺説、訂正、投与原本は別の立場の記録。初報の推測を確定した真相として扱わない。
- 古い図面は一般の施設案内から外し、設備台帳の原図番号と復旧された非掲載記事へ接続。旧基盤の入口は中盤の移管記録で知る。序盤の新聞はPDFへ直接接続する。
- 施設機関の台帳番号は初期配布資料に出さない。加入日と番号の証拠は、旧照会室の受領簿0006に置く。

## 経路と表示

27段階の根拠と権限、38研究文書の番号の入手元を照合。欠番は制作物0001–0030、企業0001–0018、保存目録0001–0012、受領簿0001–0012の連続した範囲に置く。権限のない文書は、直URLでも照会と同じ結果になる。

SEEDの異変は30回目から発動し、SEED外への到達で演出回数だけを解除する。ログイン、受領済み資料、結末は消さない。別タブの到達も反映する。動きを減らす設定では短いノイズ演出を抑える。

付箋は、PCの画面が写真左、利用者が写真右という構図で確認。文字の上端を画面側へ向け、キーボードの文字と同じ読み手に合わせた。一枚の写真として書き出し、HTMLの文字重ねは使わない。

実行環境別の到達・表示確認は[確認結果](verification.md)に記録する。利用状況を消す操作を確認手順へ含めない。
