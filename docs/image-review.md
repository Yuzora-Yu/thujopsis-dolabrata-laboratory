# 人物写真の選定記録（作者用）

人物写真は生成後にそのまま採用しない。手のある写真は、元画像で指の外形、関節のつながり、物との接触、視線の先を確認する。縮小した掲載画面だけで判断しない。

## 灯の作業写真

前の筆記写真は、指の不自然さの指摘により採用を取り消した。

同じ人物の正面写真を顔の参照として、次の3候補を新規生成し、手元を原寸で比較した。

| 候補 | 写っている動作 | 判断 |
| --- | --- | --- |
| A | 横から見た筆記 | 鉛筆と指の重なりが大きく、把持の形を十分に確認できない。採用しない |
| B | やや上から見た筆記 | 親指・人差し指と軸の位置関係に判断が残る。採用しない |
| C | 机に置いたグリップへ指を添えて確かめる | 両手の外形と指の自然な重なり、グリップとの接触を原寸で確認。作業の対象へ視線が向く。採用対象とし、掲載画面でも再確認する |

採用原本：docs/source-images/p-akari-work.png。生成元：内蔵画像生成 exec-3e6bce25-d294-41bd-bf76-3baa8e6a69c4。正確なプロンプト：docs/media-assets.json。

正面の人物写真は、手の入らない構図でカメラに視線を合わせる。作業写真と同じ服装・髪型を用い、背景と机上に広い余白を取る。

この選定は、他の人物・制作物写真まで確認済みという意味ではない。サイト全体の画像は、人物、指、接触、構造、背景の密度、色味を素材ごとに確認する。

## 追加の素材点検

全56点の一覧を照合した後、灯、文乃、朝倉、榊原、稲葉、鉛筆グリップ、生活用具、給食試験、修理部品、計測担当の手元を個別画像で確認。朝倉の測定場面は取材の人物写真へ再構成。修理部品は、D型の軸穴と造形層が分かる四部品の写真へ再構成した。後者は2015年の掲載として1100px・JPEG品質78を経てWebP化。プロンプトと生成元はmedia-assets.jsonに記載。

灯の候補Cは机へ置いたグリップの接触、見える指の接続と自然な重なり、視線を確認。A・Bは採用しない。採用外の筆記画像と旧人物画像は公開素材・プロジェクトの原本から削除する。


## 留め具の試作写真

制作物0031の旧写真は、青いレバーの支点は見えても、その回転が爪へ伝わる可動部と保持面を追えなかった。別担当も原寸で同じ範囲を点検し、隠れたカムやリンクを仮定して機能する写真として採用し続ける根拠は不足と判断した。絶対に動かないと実証したという意味ではない。

新たに、台座へ差し込む一体の青い片持ち腕を生成。最初の閉じ状態では受けの横梁が爪を隠したため、二枚の展示板を離し、受けから外した状態へ編集した候補を採用した。腕の連続性、下向きにたわむ逃げ、爪と操作面、台座の固定と接地を原寸で再確認。別担当も解放状態の試作写真として採用を支持した。交換手順・耐久・全動作を実測したことにはしない。
